# AI Image Prompts — Wine Ferrari Recreation

**Goal:** Generate 8 stills of the SAME car from 8 different angles, matching the wine ferrari video's framing, lighting, and aesthetic.

**Output specs for each still:**
- Resolution: **2160×3840** (4K vertical, 9:16 aspect ratio)
- Format: JPG or PNG, high quality
- File names (when saving): `shot1.jpg`, `shot2.jpg`, …, `shot8.jpg`

**Critical rule:** The car must look IDENTICAL across all 8 stills (same color, same body kit, same wheels, same livery, same paint condition, same ride height). Different angles, but same physical car. Different AI tools require different consistency techniques — see notes per tool at the bottom.

---

## SHARED CAR DESCRIPTION BLOCK (use this verbatim in every prompt)

Copy-paste this block into every prompt:

```
Subject: A custom widebody Ferrari supercar, deep wine-red / dark burgundy
metallic paint with subtle pearl flake. Aggressive aero kit: massive carbon-
fibre rear wing on twin endplate stands, deep front splitter, side skirts
with "NO STEP" decals on the rocker, exposed carbon honeycomb diffuser,
huge fender flares. Black 5-spoke forged wheels, low-profile Pirelli tires,
yellow Brembo brake calipers. Yellow California license plate reading
"RACIETY". Small Ferrari prancing-horse shield badge on the front fender
and engraved on the rear wing.

Setting: Pristine professional studio. Plain seamless light grey cyclorama
background (cool grey ~RGB 145,150,155, gradient slightly darker at top,
lighter at bottom). Polished light grey reflective floor with soft contact
shadow under the car and a faint mirror reflection.

Lighting: One large soft top-key light directly above and slightly camera-
front, creating a long specular highlight along the top edges of the body
panels. No fill light from below. Deep shadow on the lower half of the car
body. Single direction of lighting only.

Photography: Cinematic car commercial aesthetic, photoreal, sharp focus
across the entire car, deep depth of field, subtle film grain, no motion
blur. Shot on a high-end mirrorless camera with a prime lens. The car is
the only object in the frame — no people, no props, no other cars.

Aspect ratio: 9:16 vertical (portrait), 2160x3840.
```

## Tool-specific notes for consistency

### Google AI Studio (Nano Banana / Gemini 2.5 Flash Image) — RECOMMENDED
This is the best for object consistency. Workflow:
1. Generate **shot 1 first** with the full prompt (shared block + shot 1 framing)
2. For shots 2-8: open a new chat, **upload shot 1 as a reference image**, then write: "Generate the same car as in this reference image, but [paste the shared block + the specific shot's framing addition]."
3. Nano Banana will preserve the car's color, livery, wheels, body kit across all 8 shots.

### Midjourney
Use `--cref` (character reference) and `--sref` (style reference):
1. Generate shot 1 first with the full prompt
2. For shots 2-8, use: `[shared block + shot framing] --cref [URL_of_shot1] --cw 100 --sref [URL_of_shot1] --ar 9:16 --v 6.1`
3. `--cw 100` weights character reference at maximum. Note: Midjourney's `--cref` is tuned for human characters; consistency on cars is decent but not perfect.

### ChatGPT (GPT-4o / GPT-5 image gen)
1. Start a single conversation
2. Generate shot 1 with the full prompt
3. For shots 2-8, in the SAME conversation: "Now generate shot 2 of the SAME car. Same paint, same wheels, same body kit, same livery. Here's the framing: [framing addition]"
4. ChatGPT's image gen has decent in-conversation memory but will drift. Re-show the previous image periodically by saying "use this car" with the image attached.

### Flux (free / v1)
Flux v1 doesn't have native character reference. Best workflow:
1. Generate shot 1 with the full prompt
2. For shots 2-8, write the prompt as if describing a single specific physical car. Be very explicit and consistent in the shared block. Accept that there WILL be drift between shots.
3. **Better:** use Flux Kontext (paid, on fal.ai or Replicate) which DOES support image-conditioned editing — pass shot 1 as input image and request the new framing.

### Recommended test order
Generate shot 1 in all 4 tools first. Pick the tool that gives you the BEST shot 1. Then generate shots 2-8 in that tool only (don't mix tools across shots — the consistency will break).
